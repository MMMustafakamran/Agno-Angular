## Original findings (found on angular 0.3.1 / runtime 1.67.1)

**1. ❌ Open Generative UI sample doesn't typecheck.** [Frontend tools](https://docs.copilotkit.ai/angular/agno/guides/frontend-tools-generative-ui): `SandboxFunction<{ filter: string }>` isn't assignable to `sandboxFunctions: SandboxFunction[]` (handler is invariant). Repo casts `as unknown as` at the array site.
**2. ⚠️ "A2UI renderer activates automatically" is misleading.** [A2UI](https://docs.copilotkit.ai/angular/agno/guides/a2ui): `a2ui: {}` + `/info` `"a2uiEnabled": true`, yet agent never calls `render_a2ui` (4 runs). The frontend `a2ui.catalog` is the real switch; it can't be built from guide code (#4). Traps: catalogs need Zod 3 (`zod/v3`; Zod 4 gives an empty schema via `zod-to-json-schema@3`); don't import `DynamicString` from `@copilotkit/a2ui-renderer` (nested zod@3.25 causes TS heap exhaustion); restate it locally and cast at `createCatalog`.
**3. ❌ `openGenerativeUIEnabled` is an undocumented runtime flag.** `/info` reports `false` even with `sandboxFunctions` configured; guide documents no server counterpart.
**4. ❌ Showcase excerpts aren't self-contained.** Missing identifiers: Frontend tools `createBackgroundTool` (`resolveGradient`, `BackgroundToolArgs`); A2UI `fixedDefinitions` (`dynamicString`), `a2uiConfigForFeature` (catalogs, `createCatalog`); Voice `voiceWeatherRendererConfigs` (`VOICE_WEATHER_TOOL_NAMES`, `VoiceWeatherArgs`, `WeatherToolCard`), `createMultimodalMessage` (`SampleSpec`, `MediaAgentMessage`); HITL `InterruptFeatureComponent` (`agentIdForCurrentIntegration`, `parseInterruptPayload`, …); Headless `HeadlessChatController` (`createMessageId`, `ShowcaseMessage`). Shown as quoted, unmounted samples; A2UI runs on the default catalog.
**5. ❌ Chat UI guide reuses a name/selector.** Two samples are `SupportChatComponent`/`app-support-chat`; the popup is `AppComponent`/`app-root`. Repo renames them `CustomMessageChatComponent`, `PopupSidebarComponent`.
**6. 🛠 `agentId="support"` has no backing agent.** Quickstart registers only `default`; repo adds a `support` agent on the same Agno process.
**7. ❌ Angular/Agno quickstart has no backend step.** [Quickstart](https://docs.copilotkit.ai/angular/agno/quickstart) contains `<!-- setup skipped: agent-setup is not bundled for agno -->`; `AgnoAgent` came from the React quickstart. `server.ts` combines both pages.
**8. ❌ `zod` is an undocumented direct dependency.** Samples import `zod`; the install command omits it.
**9. 🛠 Prod bundle exceeds default budget.** 4.65 MB vs 1 MB; `angular.json` sets 5 MB warn / 7 MB error. CommonJS bailouts: `whatwg-url`, `@jetbrains/websandbox`, `partial-json`, `chalk`.
**10. 🛠 Agno tool names must be camelCase.** `@tool(name="getWeather")` with `city`; otherwise there's no card, just plain text.
**11. 🛠 Frontend-only tools need no Python declaration.** `requestApproval` is forwarded via AG-UI. The inverse (an agent tool with no frontend handler) hangs the run.
**12. ❌ Inspector version floor is misplaced.** [Inspector](https://docs.copilotkit.ai/angular/agno/inspector): the 0.4.0 floor appears only in a callout; on 0.3.1 `enableInspector` isn't in `CopilotKitConfig`. Repo bumped to ≥0.4.0.
**13. ❌ `verify` can't gate CI without Intelligence.** [CLI](https://docs.copilotkit.ai/angular/agno/cli): 3 of 7 checks are Intelligence checks that FAIL (not UNKNOWN), so a working stack exits 1. No scoping flag.
**14. ❌ `verify` reports framework as `t`.** `/info` `"className": "t"` (minified). Still reproduces on runtime 1.73.3.
**15. ❌ Recommended launcher corner covers the composer.** Inspector CSS moves the launcher bottom-left; on full-height `copilot-chat` it blocks the composer: `<cpk-web-inspector> intercepts pointer events`.
**16. ❌ Shared state is never initialised; the fallback hides it.** [Shared state](https://docs.copilotkit.ai/angular/agno/guides/shared-state): real state is `{}` while `EMPTY_STATE` renders `Priority: normal`. `agent.state ?? EMPTY_STATE` never fires on `{}`, so a write before the first run drops `notes` (`{"priority":"high"}`); order-dependent. The UI text also lets the model answer from screen context.
**17. ❌ "Your agent is listed": it isn't yet.** [Quickstart](https://docs.copilotkit.ai/angular/agno/quickstart) Inspector step shows "No agent selected" until picked via `[data-inspector-sidebar-agent-selector]`, which the step omits.
**18. ❌ Context sample is unobservable.** [Shared state](https://docs.copilotkit.ai/angular/agno/guides/shared-state) "Use London time" works on the wire (`America/Los_Angeles` → `Europe/London`) but shows nothing. Re-registration is remove+append (position 0 → 7, new id); there's no context signal, so you have to poll `core.getContextForAgent()`.
**19. ❌ `registerComponent` snippet is wrong four ways (angular 0.5.1).** [Frontend tools](https://docs.copilotkit.ai/angular/agno/guides/frontend-tools-generative-ui): (1) empty tool result makes the agent apologise (`followUp: false` fixes it; undocumented); (2) guard checks `"in-progress"`, but the status is `"executing"`; (3) status never reaches `"complete"`; (4) no CSS/whitespace: renders `INC-4711sev1`. Also: no imports, injection context unstated, description gets a preamble prepended. Not in 0.4.0, so the repo moved to 0.5.x.
**20. ❌ Same page teaches two renderer styles.** Type-only vs value imports of `AngularToolCall`/`ToolRenderer`; `standalone: true` vs none (it violates `frontend/AGENTS.md`). Both kept verbatim.
**21. ❌ Six pages moved `premium/*` → `intelligence/*` with no redirect.** Old paths 404; the drift gate exited 2. Retargeted in `sync-docs.ts`, manifest, snapshots. `connect-your-runtime` was later removed (#38).
**22. ❌ Live pages missing from the sitemap.** Sitemap lists 4 `/angular/agno` URLs; 17 live pages were reachable only by links. 16 are tracked (45 pages); `intelligence/quickstart` is deliberately untracked (`knownUnmapped`) but is now the only source for `server.ts`'s Intelligence code (#38). See #41.
**23. ❌ Two in-section links 404.** [AgentCore](https://docs.copilotkit.ai/angular/agno/deploy/agentcore) → `/angular/agno/agentcore/full-stack-example`; [Custom agent](https://docs.copilotkit.ai/angular/agno/backend/custom-agent) → `/angular/agno/advanced-configuration` (still 404; `/angular/advanced-configuration` is 200). The latter is in `knownUnmapped`, so the dead-link scan skips it; re-check with `curl -I`.
**24. ❌ Angular pages title runtime code as a Next.js route.** 20 snippets titled `app/api/copilotkit/[[...slug]]/route.ts` across `backend/copilot-runtime` (6), `copilot-runtime` (5), `backend/runtime-endpoints` (3), `backend/agent-runner` (3), `deploy/agentcore` (2), `troubleshooting/debug-mode` (1). Angular runs a Node server. One example pairs it with `src/app/app.component.html`.
**25. ❌ On an Intelligence runtime, `/run` isn't SSE (runtime 1.72.0).** It returns JSON `{threadId, runId, joinToken, realtime:{clientUrl, topic}}`. [Runtime endpoints](https://docs.copilotkit.ai/angular/agno/backend/runtime-endpoints) says SSE; [Debug Mode](https://docs.copilotkit.ai/angular/agno/troubleshooting/debug-mode) shows an SSE log (only `Agent run started` observed). Only [Event Inspector](https://docs.copilotkit.ai/angular/agno/troubleshooting/event-inspector) warns. A non-UUID `threadId` fails with `Failed to initialize thread` / `400 VALIDATION_ERROR` (undocumented).
**26. ❌ Learned skills have no Agno path; Python packages 404.** [Learned skills](https://docs.copilotkit.ai/angular/agno/intelligence/learned-skills): no Agno row; `copilotkit-intelligence-runtime`/`-langgraph`/`-adk` 404 on PyPI; no install commands. The added BuiltInAgent row means dropping Agno (#33, #34).
**27. ❌ Learning snippet uses undefined identifiers.** [Learning](https://docs.copilotkit.ai/angular/agno/learning): `agents`, `identifyUser` → `TS18004`. The example `agentId === "expense-agent"` matches nothing here.
**28. ❌ The approval card is the model's call.** [HITL](https://docs.copilotkit.ai/angular/agno/guides/human-in-the-loop) gives no prompting/tool-choice guidance; on `gpt-5.4-mini` the card failed 2/5 takes even with an explicit request. Deliberately not forced.
